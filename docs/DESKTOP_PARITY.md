# Mac 与 Windows 逐项对齐

本轮保持原有行情终端风格，Windows 使用 WinForms，Mac 使用 Avalonia 原生桌面后端。两端共享快照、指标目录、K 线聚合和营收公式。下面区分已实现的对齐与仍存在的平台差异；不能将界面一致理解为所有硬件传感器都可读取。

| 检查项 | Mac 当前实现 / 与 Windows 的关系 |
| --- | --- |
| 八项指数 | CPU 指数/负载、GPU 频率/负载、内存、GPU 温度、网络、进程数；点击切换品种 |
| 自选行情 | 指标代码、名称、现价、涨跌、迷你走势；支持板块筛选 |
| 行情摘要 | 当前值、涨跌、今开、最高、最低、均价；与 Windows 共用指标计算 |
| K 线 | 2/5/10/30/60 秒；MA5/10/20、十字线和 OHLC；缺失值不产生假蜡烛 |
| 周期按钮 | 两端均使用 22 逻辑像素高的紧凑选项；金色下划线标识选中项 |
| 采样周期 | 0.5/1/2/5/10 秒；禁用小于两倍采样间隔的 K 线周期 |
| 活跃量 | 有上下文切换计数时显示；Mac 本机缺少此传感器时不虚构成交量 |
| 暂停/恢复 | 暂停展示，恢复后接收实时采样；营收暂停结算 |
| 主力排行 / 逐笔动态 | CPU 排名前十；进程出现、退出、负载变化和资源预警 |
| 完整进程表 | 虚拟化全部当前可见进程；名称/PID 搜索、CPU/显存/内存/线程排序、升降序 |
| 进程交互 | 右键置顶、复制名称、CPU 涨跌和历史走势；仍为只读监控 |
| GPU | 可滚动总览、每卡指标和 K 线；显存按 GPU UUID 归属 |
| 本机 / SSH | 指纹核实、密码/私钥、SSH config 导入、断线重连；切换目标清空前一目标历史 |
| 断线状态 | 保留历史并标记过期，显示具体错误，不自动切成本机数据 |
| 红涨/绿涨 | 两端可切换；语义色与图表同步 |
| 主题 | 深色、浅色、跟随系统；弹窗沿用当前主题 |
| 置顶 / 全屏 | 原生窗口置顶；F11 全屏，Escape 退出 |
| 快捷键 | 空格暂停；1–5 周期；T 置顶；C 配色；E 营收；F5 刷新；F9 挂件；⌘/Ctrl+F 搜索 |
| 输入保护 | 在搜索框输入字母、数字与空格不会触发主窗口快捷键 |
| 营收模拟 | 共用 Windows `Economy.cs`；分部净收益、累计、峰值、温度系数、归零和持久化 |
| 缺失传感器 | 任一结算输入缺失时停止结算，避免 NaN 污染累计；两端共用此修复 |
| 行情播报 | 可开关；Mac 底部定期轮换指标，Windows 保留连续滚动 |
| 桌面挂件 | Mac 增加独立置顶小窗，显示 CPU/内存/GPU/网络、暂停与返回主窗 |
| 托盘 | Mac 菜单栏图标提供主窗、暂停、挂件、连接、退出；Windows 保留原托盘 |

| 设置保存 | 采样/周期、主题、配色、排序、进程置顶、窗口位置/大小、最大化、挂件、营收累计 |
| 应用图标 | Mac `.icns` 直接复用仓库原有图标；Finder/Dock 与 Windows 保持同一标识 |

## 明确的平台差异

- Mac 本机 GPU 目前只识别设备型号，GPU 利用率/显存/频率/温度/功耗/风扇、CPU 实时主频和磁盘吞吐仍不可用，显示 `—`。Apple 统一内存不会被当成独立显存。通过 SSH 连接支持这些传感器的 Linux 服务器可显示远端读数。
- Windows 的桌面嵌入壁纸模式依赖 Win32；Mac 提供置顶挂件，不提供同等的桌面底层嵌入。Mac 关闭主窗口结束应用，Windows 保留关闭到托盘的行为。
- Mac 图表按新采样刷新；Windows 保留数值和 K 线缓动。Mac 的挂件内容、行情轮播形式与 Windows 并非逐像素复刻。
- Mac SSH 密码/私钥口令仅在当前进程内保存；Windows 使用当前用户的加密存储。Mac 未接入 SSH agent/钥匙串。
- Mac 是 ad-hoc 签名，没有 Apple Developer ID 公证；第一次打开需要用户按系统提示单独允许。见 [首次打开说明](MACOS_FIRST_OPEN.txt)。

原生 UI 自动化使用实际生产窗口和渲染后端。Mac 使用真实本机采样和隔离 SSH 服务；Windows 本轮 UI 截图使用标明 `UI validation fixture` 的合成数据，避免修改用户连接、设置或登录项，不将其当成硬件准确性验证。
