# 在另一台电脑使用

## 运行程序

客户端支持 Windows 10/11 x64。解压便携包后双击 `PerfTickerRemote.exe`，无需安装 .NET、Python 或 SSH 客户端。
也可以从源码构建（需要 .NET 10 SDK）：

```powershell
dotnet publish PerfTicker/PerfTicker.csproj -c Release -o dist
.\dist\PerfTickerRemote.exe
```

GitHub 的 Code → Download ZIP 是源码压缩包，并非已编译程序。Linux/macOS 电脑不能直接运行这个 Windows exe。

## 选择监控对象

左上角齿轮 → **监控目标 → 切换**：

- **这台电脑（Windows 本机）**：直接采集本机，不用配置 SSH。
- **SSH 服务器（Linux）**：填写或导入连接参数，保存并切换。

首次运行且没有旧连接配置时默认监控本机；已有远程配置的用户保留服务器模式。以后记住最后选择。
切换目标会重新积累 K 线、进程历史和模拟营收；断线只会尝试重连原服务器，不会自动改成本机。

## 接入 SSH 服务器

1. 程序自动读取当前电脑 `%USERPROFILE%\.ssh\config`，在“已配置 SSH 主机”选择条目即可填入地址、端口、用户名和私钥路径；也可全部手动填写。
2. 主机填写 IP 或域名，SSH 端口填写实际端口（通常为 22）。IPv6 可填写不带方括号的地址。
3. 认证方式选择密码，或选择此电脑上的 SSH **私钥**文件；加密私钥还需填写私钥口令。
4. 点击“检测 SSH / 读取指纹”。这一步只检查 SSH 握手，不发送登录密码。
5. 向管理员核对指纹，或在服务器查看公开的主机密钥指纹，再勾选“我已核实”。检测到与已保存指纹不一致时不会自动覆盖。
6. 点击“测试登录与显卡”。成功后会显示服务器名称、线程数与检测到的 NVIDIA 显卡数量。
7. 点击“保存并切换”，开始接收行情。

服务器可用下面的命令列出主机公钥指纹，与程序实际协商到的算法对应项比较：

```sh
for key in /etc/ssh/ssh_host_*_key.pub; do
  ssh-keygen -lf "$key" -E sha256
done
```

服务器需要能通过 SSH 访问，安装 Python 3；NVIDIA 显卡需要驱动和 `nvidia-smi`。程序只读 `/proc`、`/sys` 和 GPU 指标，不安装服务。普通 SSH 用户通常可以使用，受限进程信息可能不可见。

## 自动识别的范围

- 读取常用的 `Host`、`HostName`、`Port`、`User`、`IdentityFile`，支持多个别名、通配默认值和带引号的私钥路径。
- 不扫描整个局域网、不猜测密码，也不接管已经打开的终端 SSH 会话。
- 不从终端提取密码，不自动使用 ssh-agent；需要选择私钥文件或输入密码。
- `Include` / `Match` 不展开；`ProxyJump` / `ProxyCommand` 不执行。涉及这些选项时请核对参数，使用可直达地址或已建立隧道的本地转发端口。
- IP 可达不等于能登录；“测试登录与显卡”还会验证账号认证、Python 采集器和实际返回的数据。

若使用 IPv6 链路本地地址，末尾 `%接口编号` 必须属于**当前电脑**。换电脑后不能原样复制旧编号；可运行 `Get-NetIPInterface -AddressFamily IPv6` 查看 `ifIndex`。跨网络连接通常应使用可路由 IP/域名、VPN 或 SSH 隧道。

## 四张、八张或更多显卡

不需要手填显卡数量。设置 → **显卡总览 → 查看**，可以同时查看全部已枚举 GPU 的型号、负载、已用/总显存、温度、功耗与核心频率。
选择一行后点击“查看所选显卡 K 线”，或双击该行。左侧“图形”分类也包含逐卡指标。

多卡汇总口径：负载/频率取平均，显存/功耗求和，温度/风扇取最高值。若任一卡缺少某项传感器，该项汇总显示“—”，避免把部分读数冒充全机总值。
远程进程表显示全部 GPU 的显存合计；选中某张卡的指标时，右侧持仓只统计该卡。不会把显存使用比例当作 GPU 利用率。

## 换电脑与日常操作

只需复制程序或便携包；不要复制 `%LOCALAPPDATA%\PerfTickerRemote\remote.json`。其中密码和私钥口令使用 Windows 当前用户加密，不能跨电脑解密。私钥文件保留在用户指定位置，不打包进程序。

关闭主窗口会缩到托盘；完全退出请使用托盘右键菜单“退出”。配置出错时打开“诊断日志”，也可重新进入监控目标设置修改参数。
